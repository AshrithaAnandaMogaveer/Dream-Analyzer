📝 MANUAL SETUP (IF AUTOMATED FAILS):

   Step 1: Get OpenAI API Key
   ─────────────────────────────
   • Go to: https://platform.openai.com/api-keys
   • Create account / Log in
   • Click "Create new secret key"
   • Copy the key (starts with sk-)

   Step 2: Add API Key
   ─────────────────────────────
   • Open: server/.env
   • Find line: OPENAI_API_KEY=PLEASE_ADD_YOUR_OPENAI_KEY_HERE
   • Replace with: OPENAI_API_KEY=sk-your-actual-key
   • Save file

   Step 3: Start Backend
   ─────────────────────────────
   • Open terminal/PowerShell
   • Run: cd server
   • Run: npm install (first time only)
   • Run: npm start
   • Wait for: "Server running on port 5000"

   Step 4: Start Frontend
   ─────────────────────────────
   • Open NEW terminal/PowerShell
   • Run: cd client
   • Run: npm install (first time only)
   • Run: npm start
   • Browser opens automatically

   Step 5: Test
   ─────────────────────────────
   • Go to: http://localhost:3000/chatbot
   • Create account / Log in
   • Type: "I was flying over mountains"
   • AI should mention "flying" and "mountains"
